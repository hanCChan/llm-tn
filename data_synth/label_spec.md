# 标注口径 v2（LABEL_SPEC）

> 训练数据生成器、新评测集写作者、gold 修订**共用这一份**口径。来源：人工训练集
> `data/train_merged.jsonl`（4167 条）的既有标注习惯 + 用户 2026-10-22 指示（序列号含字母）。
> 训练集里没出现过的写法，按下面的**总原则**推出，不看测试集错例定口径。

## 总原则

1. **span = 必须和数字一起读的完整写法**：前缀（币种符号/币种代码/字母/`V`/`+`/`#`/`√`/括号区号）、
   后缀（单位、量词、`年月日号`、`点 点半 点整 时分秒`、`am/pm`、`%`、`号楼室弄`…）、范围两端及连接符
   （`至 到 ~ - — –`）都在 span 内。
2. **不进 span**：时段词（上午/下午/凌晨/晚上…）、修饰词（约/大约/近/超过/共）、引导语（电话/编号/型号/版本…）、
   句读标点、span 外的括号说明。
3. **只标阿拉伯数字相关的写法**：纯汉字数字（两点半、三十多岁）不标；罗马数字、全角数字视同数字。
4. **"品牌/产品名 + 空格 + 数字" 不标**（`iPhone 15`、`Python 3`、`Windows 11`、`USB 3.0`、`Boeing 737`）——
   这是人工训练集的既定负例口径；**字母与数字紧连**的编码才是 SERIAL（`S23`、`A330`、`H1N1`）。
5. 一个连续表达只标一个 span，选一个类；类别按**语义**定，不按外形。
6. 标签格式 `["原文片段", "CLASS:class"]`（小写重复类名），片段必须是原文的精确子串。

## 12 类

| 类 | 是什么 | 例（span 用【】） |
|---|---|---|
| DATE | 日期、年份、月日、年代、`a/b` 表示日期 | 【2024年3月5日】【3/15】出发、【2025.10.8】、【1990年代】、【12月3号】 |
| TIME | 时刻、时刻区间 | 下午【3:30】、【9点】、【8点半】、【7:00am】、【10:30 p.m.】、【14:05:33】、【9:00-17:30】 |
| MONEY | 金额（含币种/单位/万亿） | 【¥88】、【HK$1,200】、【USD 300】、【3.5万元】、【200欧元】、【$5.2亿】、【100-200元】 |
| MEASURE | 带单位/量词的量（含时长、年龄、温度、计数量词） | 【24小时】、【3分45秒】（作时长）、【18岁】、【-5℃】、【120km/h】、【3个】、【500ml】 |
| PERCENT | 百分数、千分数及区间 | 【35%】、【-2.5%】、【3‰】、【10%~15%】 |
| FRACTION | 分数、比例写成 `a/b` 或 Unicode 分数 | 【2/3】的选票、【⅓】 |
| SCORE | 比分、比赛/投票结果 | 以【3:1】获胜、【25-23】、【2比0】（阿拉伯数字时） |
| MATH | 算式、方程、函数式、带变量的数学表达 | 【3×4=12】、【y=2x+1】、【f(x)=x^2】、【√16=4】、【a+b】 |
| PHONE | 电话号码（手机/座机/热线/国际/分机），整个号码一个 span | 【13812345678】、【(010)8888 6666】、【+86 138 0013 8000】、【400-820-8820】、【0755-1234567转801】 |
| SERIAL | 编号/型号/证件号/车牌/单号/账号，**字母+数字整体** | 【S23】、【A330】、【京A·12345】、【G12345678】、【SF1234567890】、【#2023-5678】、【dell3301】 |
| VERSION | 软件/固件版本号（含 `V`/`v` 前缀） | 【V2.3.1】、【v10.0】、版本【3.12.4】 |
| ADDRESS | 门牌、楼栋单元室号 | 人民路【88号】、【3号楼2单元501室】、【1025弄8号】、【3-1-3805】 |

## 易混判据（按语义）

- `a/b`：表示月日 → DATE；表示占比/分数 → FRACTION。
- `a:b`：时刻 → TIME；比分/票数 → SCORE；比例运算 → MATH。
- `a-b`：比分 → SCORE；日期 → DATE；号码 → PHONE；楼栋单元 → ADDRESS；减法 → MATH；数值范围 → 所属量的类（MEASURE/MONEY…）。
- 纯数字串：可拨打的号码 → PHONE；单号/证件/编号 → SERIAL。
- `3分45秒`：完成用时 → MEASURE；钟表时刻 → TIME。
